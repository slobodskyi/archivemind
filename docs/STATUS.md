## 1. Мета

AI-workspace для архіву фото творця: нескінченне полотно з фото користувача, AI-аналіз
(теги, факти, підписи, ембеддинги — **лише по кнопці**), пошук природною мовою,
експорт (PDF / captions CSV / ZIP) і чернетки статей/каруселей з публічним превʼю.
Стек: pnpm + turborepo; `apps/web` (Next.js, Vercel), `apps/worker` (Railway),
`packages/shared`, Supabase (EU) + Cloudflare R2, Gemini.

- Бізнес-ціль, цільова дата запуску, бюджет, перші клієнти: **невідомо** (у репозиторії не зафіксовано).
- Зовнішніх користувачів поки немає; прод-БД служить і спільним тестовим середовищем (PLAN.md, ADR/CONTRIBUTING).
- Стан продукту в бриф-документі: `docs/PRODUCT_SUMMARY.md` (на момент складання — неприкомічений, не мій).

## 5. Проблеми

- **Міграції на проді:** `supabase db push` кілька разів друкував помилку `pgdelta` вже після успішного застосування або падав до запису в ledger (22.07, reconcile через `migration repair`). Docker на машині власника повертає 500, тому `db diff`/`db dump` не завжди працюють (PLAN.md, 27.07, 10.08).
- **Колізія міграцій** `20260722000003` між двома гілками — урок: два гілки не можуть брати один номер.
- **Ink на проді невидимий:** після перенесення малювання на нотатку старі `kind='ink'` рядки не рендеряться; видаляти чи ні — відкрите рішення.
- **Usage & Storage** ніхто, крім власника, не бачив у браузері (PLAN.md).
- **Ризик ledger:** #80 — retry повторно білить завершені юніти.
- **Аналітика:** є PostHog session replay (ADR 0050), інших продуктових метрик немає (PRODUCT_SUMMARY.md, на момент його складання).
- **Інструменти в цій сесії:** `preview_start` не читає `.claude/launch.json` (EPERM, macOS file-access permission для застосунку) — потрібен доступ у System Settings → Privacy & Security.
- **Гілки:** 5 локальних гілок мають видалений upstream (`gone`), `claude/adoring-lalande-488886` без upstream, два detached worktree у `.claude/worktrees/` — прибирання не робилось.
- **Дерево між сесіями змінюється без запису** (див. п. 3.2) — перед роботою звіряти `git branch --show-current` і `git stash list`.
